# test10 EA

MT5用のマルチタイムフレーム型FX自動売買EAです。相場環境を判定したうえで、トレンド相場とレンジ相場それぞれの方針に沿ってエントリーします。

## 基本方針

- 上位足で相場環境と方向性を判断し、下位足でエントリータイミングを判断します。
- トレンド相場では、原則として上位足の方向に沿った売買を行い、押し目からの再加速やトレンド継続などをエントリー機会として扱います。
- レンジ相場では、価格が一定範囲から外れた後の戻りを利用した逆張りを行います。
- 相場環境や方向を十分に判断できない場合は、新規エントリーを抑制します。
- エントリーと追撃は、相場環境・方向・シグナル・既存ポジションなどを考慮して制御します。

## エントリーと決済の独立性

- 新規エントリーを許可するかどうかと、既存ポジションを決済するかどうかは独立して判定します。
- エントリー条件が不成立、相場環境が不明、またはエントリー用の指標を取得できない場合でも、それだけを理由に既存ポジションの決済監視を停止しません。
- 決済に必要なデータが取得できる限り、決済条件の監視を継続します。データが不足して判定できない場合は、新規エントリーの不成立とは区別して扱います。
- 新規発注時にはSL・TPを設定します。SL・TPによる保護と、EAが条件を監視して行う決済は別の仕組みとして扱います。
- ストキャスティクス等の指標による決済は、エントリーの可否に依存させません。トレンド相場とレンジ相場では相場に応じた決済方針を用い、共通条件を用いる場合もエントリー条件と混同しません。

## リスク管理

- ポジションごとに損失を限定するためのSL・TPを設定します。
- トレンドポジションでは、相場の進行に応じてSLを有利な方向へ更新するトレーリングを使用します。
- SLを不利な方向へ動かすことはしません。
- 取引セッションの終了前には新規エントリーを停止し、週末の長時間休場前には対象ポジションを決済する方針です。

## 取引記録と分析

取引記録は、用途を分けて管理します。

- **取引分析データ：** AIによる戦略・取引結果の分析に必要な、エントリー・決済・約定・ポジション・相場状態などの情報を記録します。取引イベントの記録を欠落させず、取得できた値と取得できなかった値を区別します。
- **テスト結果：** 損益、勝率、プロフィットファクター、ドローダウン、取引回数など、テスト全体の成績を確認します。
- **通常ログ：** 人間がエラー、注文失敗、データ取得失敗、処理上の異常などを調査するために使用します。

取引分析データは解析に必要な範囲にとどめ、過剰に細かい情報を無制限に記録することは避けます。特殊な取引イベントについても、取得可能な基本情報は記録し、復元できない情報を推測値で埋めません。
